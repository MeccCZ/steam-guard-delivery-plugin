# Steam Guard Delivery

Плагин для FunPay Cardinal автоматически выдаёт Steam Guard коды покупателям после оплаты и по команде в личном чате FunPay.

**Версия 1.1.2** · [Скачать файл плагина](https://raw.githubusercontent.com/MeccCZ/steam-guard-delivery-plugin/v1.1.2/steam_guard_delivery.py) · [Релиз 1.1.2](https://github.com/MeccCZ/steam-guard-delivery-plugin/releases/tag/v1.1.2)

## Что нового в 1.1.2

- Кнопка «Команда» сохраняет `!steam`, `/code` или фразу вроде `дай код`. Кнопка сразу показывает новое значение.
- «Назад» и «Отмена» закрывают незавершённый ввод. При возврате сохраняется страница списка плагинов Cardinal.
- В настройках доступны срок или лимит выдач, поиск и удаление записей с подтверждением, списки аккаунтов и покупателей с разбивкой по страницам.

Полная [история изменений](CHANGELOG.md).

## Установка и обновление

Нужен Python 3.11+ и FunPay Cardinal с настроенным Telegram-ботом. Для обработки новых заказов используйте Cardinal v0.1.17.17 или новее. Эта версия исправляет чтение обновлённой страницы продаж FunPay. [Обновление Cardinal](https://github.com/sidor0912/FunPayCardinal/releases/tag/v0.1.17.17)

1. Скачайте [`steam_guard_delivery.py`](https://raw.githubusercontent.com/MeccCZ/steam-guard-delivery-plugin/v1.1.2/steam_guard_delivery.py) и остановите Cardinal.
2. При обновлении сохраните копии папки `storage/plugins/steam_guard/` и старого файла `plugins/steam_guard_delivery.py`.
3. Поместите новый файл в папку `plugins/`. Оставьте `storage/plugins/steam_guard/` на месте. В ней хранятся покупатели, аккаунты и настройки.
4. Запустите Cardinal. В личном чате с ботом откройте **Плагины → Steam Guard Delivery → Настройки**. После обновления проверьте списки аккаунтов и покупателей.

Подробные шаги описаны в [инструкции по установке](INSTALLATION_RU.md).

## Настройка

1. Нажмите **Добавить аккаунт** и отправьте `НазваниеАккаунта|shared_secret`. Значение `shared_secret` берётся из `.maFile` вашего Steam-аккаунта.
2. Укажите название аккаунта в кратком описании лота FunPay. Например, для аккаунта `MyAccount` подойдёт `Steam аккаунт MyAccount`.
3. Выберите режим доступа и задайте срок или лимит. Нажмите **Команда**, если хотите заменить стандартную `!code`.

| Настройка | Как работает | По умолчанию |
| --- | --- | --- |
| По времени | Доступ действует заданное число дней. `0` означает бессрочный доступ. | 30 дней |
| По количеству | Покупатель получает заданное число выдач. | 5 выдач |
| Код сразу после покупки | Отправляет первый код и учитывает его в лимите. | Включено |
| Команда | Покупатель отправляет этот текст целиком в личном чате FunPay. | `!code` |

Срок и лимит фиксируются для конкретной покупки. Если отправка сразу после оплаты выключена, покупатель может запросить код командой.

## Данные

Плагин хранит файлы в `storage/plugins/steam_guard/`.

- `buyers.json` — доступы, сроки и счётчики выдач.
- `accounts.json` — Steam-аккаунты и их ключи.
- `settings.json` — настройки плагина.

Храните резервную копию там, где доступ к ней есть только у вас. В `accounts.json` находятся ключи Steam Guard.

## Поддержка

Если покупатель не получил код, проверьте версию Cardinal, краткое описание оплаченного лота и запись в списке покупателей. Журнал можно получить командой `/logs` в Telegram или открыть файл `logs/log.log` на сервере.

# 🚀 Установка Steam Guard Delivery Plugin

## Требования

- Python 3.7+
- FunPay Cardinal v1.0+
- Telegram бот (настроенный в Cardinal)

## Быстрая установка

### 1. Скачайте плагин

```bash
# Скачайте файл напрямую (последняя версия)
wget https://raw.githubusercontent.com/MeccCZ/steam-guard-delivery-plugin/main/steam_guard_delivery.py

# Или конкретную версию
wget https://raw.githubusercontent.com/MeccCZ/steam-guard-delivery-plugin/v1.1.0/steam_guard_delivery.py

# Или клонируйте весь репозиторий
git clone https://github.com/MeccCZ/steam-guard-delivery-plugin.git
```

### 2. Установите в Cardinal

```bash
# Скопируйте файл в папку plugins
cp steam_guard_delivery.py /path/to/FunPayCardinal/plugins/

# Перезапустите Cardinal
cd /path/to/FunPayCardinal
python main.py
```

### 3. Проверьте установку

В логах должна появиться строка:
```
[INFO] Плагин Steam Guard Delivery v1.1.0 инициализирован
```

## Настройка

### Шаг 1: Получите shared_secret

1. Откройте папку Steam Desktop Authenticator
2. Найдите файл `.maFile` вашего аккаунта
3. Откройте его в текстовом редакторе
4. Найдите строку `"shared_secret"`
5. Скопируйте значение

**Пример maFile:**
```json
{
  "shared_secret": "wB2k7j9L3mN5pQ8rT1vX4yZ6aB2cD4eF=",
  "account_name": "MyAccount",
  "identity_secret": "...",
  ...
}
```

### Шаг 2: Добавьте аккаунт через Telegram

1. Откройте Telegram бота FunPay Cardinal
2. Перейдите: **Плагины** → **Steam Guard Delivery**
3. Нажмите **⚙️ Настройки**
4. Нажмите **➕ Добавить аккаунт**
5. Отправьте: `НазваниеАккаунта|shared_secret`

**Пример:**
```
MyAccount|wB2k7j9L3mN5pQ8rT1vX4yZ6aB2cD4eF=
```

### Шаг 3: Настройте режим доступа

В настройках плагина выберите режим контроля доступа:

#### 🔢 **Режим "По количеству"** (рекомендуется)
Покупатель получает ограниченное количество кодов:
1. Нажмите **🔄 Режим** и выберите "По количеству"
2. Нажмите **🔢 Лимит кодов** и установите нужное количество (например, 5)
3. Покупатель сможет запросить только 5 кодов

**Преимущества:**
- Контроль использования
- Предотвращение злоупотреблений
- Идеально для разовых продаж

#### ⏰ **Режим "По времени"** (классический)
Покупатель может запрашивать коды неограниченно в течение срока:
1. Нажмите **🔄 Режим** и выберите "По времени"
2. Нажмите **⏰ Срок доступа** и установите количество дней (0 = бесконечно ♾️)
3. Покупатель сможет запрашивать коды в течение указанного периода

**Преимущества:**
- Долгосрочный доступ
- Подходит для VIP клиентов
- Неограниченное количество кодов

### Шаг 4: Настройте лот на FunPay

Добавьте название аккаунта в описание лота:

```
Steam аккаунт MyAccount
Уровень: 50
Prime статус
Игры: CS2, Dota 2
```

**Важно:** Название аккаунта должно точно совпадать с тем, что вы указали в плагине.

## Проверка работы

### Тест 1: Проверка генерации кода

1. В Telegram боте откройте **Плагины** → **Steam Guard Delivery** → **⚙️ Настройки**
2. Нажмите **📋 Список аккаунтов**
3. Проверьте, что код генерируется и совпадает с Steam Mobile Authenticator

### Тест 2: Команда !code

1. Создайте тестовый заказ или вручную добавьте покупателя в базу
2. Напишите в чат с покупателем: `!code`
3. Проверьте, что бот отправил код с правильной информацией о доступе

**Режим "По количеству":**
```
📊 Использовано: 1/5 кодов
✅ Осталось кодов: 4
```

**Режим "По времени":**
```
📅 Доступ истекает через 30 дн. (05.08.2026)
📊 Код использован 1 раз(а)
```

### Тест 3: Поиск покупателя

1. Откройте **👥 Список покупателей**
2. Нажмите **🔍 Поиск и удаление покупателя**
3. Введите username тестового покупателя
4. Проверьте что информация отображается корректно

## Настройки

Все настройки доступны через Telegram бота:

| Настройка | Описание | По умолчанию |
|-----------|----------|--------------|
| **Плагин включен** | Включить/выключить плагин | ✅ Включен |
| **Режим** | `time` (по времени) или `count` (по количеству) | `time` |
| **Срок доступа** | Количество дней для режима "По времени" | 30 дней |
| **Лимит кодов** | Количество кодов для режима "По количеству" | 5 кодов |
| **Команда** | Команда для запроса кода | `!code` |

### 🔢 Режим "По количеству"

При выборе этого режима покупателям выдается ограниченное количество кодов.

**Как настроить:**
1. Настройки → **🔄 Режим** → Переключите на "По количеству"
2. Настройки → **🔢 Лимит кодов** → Введите число (например, 5)

**Что видит покупатель:**
```
🔐 Steam Guard код для аккаунта MyAccount:

AB123

⏰ Код действителен 30 секунд
📊 Использовано: 3/5 кодов
✅ Осталось кодов: 2
```

После использования всех кодов:
```
❌ Вы использовали все доступные коды (5/5).
Для получения новых кодов необходимо повторно приобрести товар.
```

### ⏰ Режим "По времени"

При выборе этого режима покупатели могут запрашивать коды неограниченно в течение срока.

**Как настроить:**
1. Настройки → **🔄 Режим** → Переключите на "По времени"
2. Настройки → **⏰ Срок доступа** → Введите количество дней
   - `30` = 30 дней доступа
   - `0` = бесконечный доступ ♾️

**Что видит покупатель:**
```
🔐 Steam Guard код для аккаунта MyAccount:

AB123

⏰ Код действителен 30 секунд
📅 Доступ истекает через 25 дн. (22.05.2026)
📊 Код использован 15 раз(а)
```

При бесконечном доступе:
```
📅 Доступ: бесконечный ♾️
📊 Код использован 42 раз(а)
```

## Решение проблем

### Плагин не загружается

**Проблема:** В логах ошибка "невалидный UUID"

**Решение:** Убедитесь, что вы скачали последнюю версию плагина

---

### Код не совпадает с Steam Mobile Authenticator

**Проблема:** Генерируемый код не совпадает с кодом в приложении

**Решение:** Синхронизируйте время на сервере
```bash
sudo ntpdate -s time.nist.gov
```

---

### Покупатель не получает код автоматически

**Проблема:** При покупке код не отправляется

**Решение:**
1. Проверьте, что название аккаунта есть в описании лота
2. Проверьте, что аккаунт добавлен в базу (📋 Список аккаунтов)
3. Проверьте логи: `grep "steam_guard" logs/FPC.log`

---

### Команда !code не работает

**Проблема:** Покупатель пишет `!code`, но ответа нет

**Решение:**
1. Проверьте, что плагин включен
2. Проверьте, что у покупателя есть доступ (👥 Список покупателей)
3. Проверьте логи: `grep "steam_guard" logs/FPC.log`

---

### Покупатель не может удалить свой аккаунт

**Проблема:** Много кнопок удаления, непонятно как найти нужного

**Решение (v1.1.0+):**
1. Используйте **🔍 Поиск и удаление покупателя**
2. Скопируйте username покупателя из списка
3. Вставьте в поиск и подтвердите удаление

---

### Нужно ограничить количество выдач кодов

**Проблема:** Покупатель запрашивает слишком много кодов

**Решение (v1.1.0+):**
1. Переключитесь на **🔢 Режим "По количеству"**
2. Установите лимит (например, 5 кодов)
3. После использования всех кодов доступ автоматически закроется

## Безопасность

⚠️ **ВАЖНО:**

1. **Храните shared_secret в безопасности**
   - Не передавайте третьим лицам
   - Не публикуйте в открытом доступе

2. **Регулярно делайте резервные копии**
   ```bash
   cp -r storage/plugins/steam_guard/ backups/steam_guard_$(date +%Y%m%d)/
   ```

3. **Ограничьте доступ к файлам**
   ```bash
   chmod 600 storage/plugins/steam_guard/*.json
   ```

4. **Используйте сложные пароли**
   - Для доступа к серверу
   - Для Telegram бота

### Обновление с v1.0.0 на v1.1.0

**⚠️ Важно:** Ваши данные (аккаунты и покупатели) НЕ будут потеряны!

1. **Остановите Cardinal**
   ```bash
   # Нажмите Ctrl+C в терминале
   ```

2. **Сделайте резервную копию (опционально)**
   ```bash
   cp plugins/steam_guard_delivery.py plugins/steam_guard_delivery.py.v1.0.0
   cp -r storage/plugins/steam_guard/ storage/plugins/steam_guard_backup/
   ```

3. **Скачайте новую версию**
   ```bash
   wget https://raw.githubusercontent.com/MeccCZ/steam-guard-delivery-plugin/v1.1.0/steam_guard_delivery.py -O plugins/steam_guard_delivery.py
   ```

4. **Запустите Cardinal**
   ```bash
   python main.py
   ```

5. **Проверьте версию в логах**
   ```
   [INFO] Плагин Steam Guard Delivery v1.1.0 инициализирован
   ```

6. **Проверьте что все работает**
   - Откройте Telegram бота
   - Зайдите в настройки плагина
   - Проверьте что все аккаунты и покупатели на месте
   - Новая кнопка **🔄 Режим** должна появиться

### Что нового в v1.1.0

- 🔢 **Режим "По количеству"** - ограничение на N выдач кодов
- ⏰ **Улучшенный режим "По времени"** - бесконечный доступ (0 = ♾️)
- 🔍 **Умный поиск** - поиск покупателей и аккаунтов для удаления
- 📊 **Счетчик использований** - статистика по каждому покупателю
- 🎨 **Улучшенный интерфейс** - чистые списки без десятков кнопок

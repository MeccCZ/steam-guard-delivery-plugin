# Changelog

Все значимые изменения в этом проекте будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.1.0] - 2026-07-06

### ✨ Добавлено
- **Два режима доступа:**
  - 🔢 **По количеству** - лимит на N выдач кодов (например, 5 кодов)
  - ⏰ **По времени** - доступ на N дней или бесконечно (как раньше)
- Переключение режима одной кнопкой в настройках
- Настройка лимита кодов для режима "По количеству"
- Счетчик использованных кодов для всех режимов
- Информация об остатке кодов в сообщениях покупателям
- Предупреждение "⚠️ Это был ваш последний код!"

### 🔄 Изменено
- Убрана кнопка "Авто-отправка" (теперь всегда активна)
- Улучшен интерфейс списка покупателей - теперь одна кнопка "🔍 Поиск и удаление"
- Улучшен интерфейс списка аккаунтов - теперь одна кнопка "🔍 Поиск и удаление"
- Расширена информация в списке покупателей (показывается использование кодов)
- Обновлено описание плагина

### 🐛 Исправлено
- Оптимизирован интерфейс для работы с большим количеством покупателей
- Улучшена читаемость списков (убраны десятки кнопок)
- Добавлена поддержка бесконечного доступа (0 дней = ♾️)

### 📊 База данных
- Добавлено поле `codes_used` для отслеживания использований
- Добавлено поле `codes_limit` для режима "По количеству"
- Поле `expires_at` теперь может быть `null` (бесконечный доступ)
- Полная обратная совместимость со старыми данными

## [1.0.0] - 2026-04-27

### Добавлено
- ✨ Автоматическая выдача Steam Guard кода при покупке
- ✨ Команда `!code` для запроса кода
- ✨ Ограничение доступа на 30 дней (настраивается)
- ✨ База данных покупателей с отслеживанием срока
- ✨ Управление через Telegram бота
- ✨ Поддержка множества Steam аккаунтов
- ✨ Генерация кодов из shared_secret (локально)
- ✨ Логирование всех операций

### Исправлено
- 🐛 Удаление невидимых Unicode символов из команд FunPay
- 🐛 Корректная обработка сообщений без водяных знаков
- 🐛 Правильная регистрация обработчиков Telegram

### Безопасность
- 🔐 Локальная генерация кодов (shared_secret не передается)
- 🔐 Проверка срока доступа перед выдачей кода
- 🔐 Логирование всех запросов кодов
